# How to Install the More Mobs Addon

There are two ways to install this addon to your Minecraft Bedrock Edition:

## Method 1: Easy Install (Recommended)
1. Locate the `MoreMobs.mcaddon` file.
2. **Double-click** (or tap) the file.
3. Minecraft will open and automatically import both the Behavior Pack and the Resource Pack.
4. When creating a new world or editing an existing one:
   - Go to **Resource Packs** and activate "More Mobs RP".
   - Go to **Behavior Packs** and activate "More Mobs BP".
   - **Important:** Ensure that "Holiday Creator Features" is enabled in the Experiments toggle if any issues occur.

## Method 2: Manual Installation
If you need to move the folders manually, follow these paths:

### 1. Locate your Minecraft 'com.mojang' folder:
- **Windows**: `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\`
- **Android**: `/Android/data/com.mojang.minecraftpe/files/games/com.mojang/`
- **iOS**: `On My iPhone/iPad > Minecraft > games > com.mojang`

### 2. Move the folders:
- Move the `BP` folder to `com.mojang/development_behavior_packs/` (rename it to `MoreMobsBP`).
- Move the `RP` folder to `com.mojang/development_resource_packs/` (rename it to `MoreMobsRP`).

## Verification
To check if the addon is working, look for the following spawn eggs in the Creative Inventory:
- **Spawn Forest Guardian**
- **Spawn Desert Stinger**
- **Spawn Cloud Ray**
